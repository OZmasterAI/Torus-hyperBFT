# Testnet genesis and launch: checklist (draft)

Status: draft, s136 (2026-10-22), against main `9ea22dbd`. For the owner to decide later. This file lists every open
question about the testnet genesis file and the launch, with its options and what we know. It recommends nothing.
Items already decided are marked **decided**, with the session and the source. No testnet exists yet; every run so
far is a local devnet or a one-host bench. The trial net (archy + cachyoz + 18c, roadmap "Trial net") comes first.

Paths: **RM** = `docs/Torus-hyperBFT-roadmap.md` (line numbers at the s136 refresh), **GEN** =
`crates/torus-genesis/src/lib.rs` on main, **CR** = `docs/configuration-reference.md`.
Status values: **decided**, **open**, **conflict** (sources disagree; owner to confirm), **pending code** (decided,
waiting for a merge). "Blocks" names what cannot be finished until the item is settled.

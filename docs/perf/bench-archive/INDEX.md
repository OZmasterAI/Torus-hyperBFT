`/home/oz/bench-results-matched/`; none of it is in git. This archive is the docs side of a clean-up: it records where

* **Scope.** 215 directories at the top level of `~/bench-results-matched`, plus 518 small top-level files
  (campaign drivers `*-campaign.sh`, campaign logs and done markers, per-cell `*.campaign.log` / `*.cell.rc`, analysis
  `*.md` / `*.txt` / `*.py`, ~4 MB in total). The top-level files are small and are kept; several docs cite them by name.
* **Skipped (in use at archive time).** `read-precompile-gas-ac` (owner instruction) and every dir with a file modified in the
  last 60 minutes (`presuite-4164382d`, `presuite-76eb081c`, `presuite-ae767806`). They are listed below but not inventoried and not in `DELETABLE.md`. (s29: all 4 now inventoried, see the update note.)
* **Sizes** are the sum of file sizes (`du --apparent-size` style), taken at archive time. The inventoried dirs (all but the 4 skipped) hold 8.69 GiB.
* **Dates** are the file-mtime range (local date, ozarchy).
* **Commit(s) / branch** come from each cell's `summary.json` (`worktree @ commit`, node binary md5 in brackets), not from the dir name.
* **What a cell dir holds.** A matched-bench cell (`ozarchy-<tag>-<cell>`) has `summary.json`, `run.log`, `bench.log`,
  `agreement.jsonl`, `analysis-val*.txt`, `digest-*`, `drain*`, `funnel-val*.csv`, `phase-val*.csv`, `metrics-{before,after}-val*.txt`,
  `cpu.csv`, `schedstat.*`, `state-digest-val*.txt`, `val*.log.excerpt` (small, keep) and the bulky `val*.log.gz` (raw node logs),
  `buckets.csv`, `tasks.txt`, `sampler.csv`; profiled cells add `perf.data`, `perf.folded`, `prof-*`; liquidation / ADL cells add
  `liq-stress.json`, `liq-lines-val*.txt`, `thin-snap.jsonl`; 300-market cells add `genesis-3val.json`. `*-tools` dirs hold analysis scripts and
  derived perf dumps; `*-build` dirs hold build logs and binary md5s; `ubench-*` dirs hold microbench logs, perf data and staged binaries.
* **Recorded in** = where the results are written up. Section names are copied from the doc headings. Almost everything is in
  `docs/perf/ozarchy-antispam-item6-pf1-2026-10-04.md` (the long ozarchy doc, "the ozarchy doc" below). Per-cell numbers for every cell with a `summary.json` are in `cells.md`.
* **Status codes:** R = recorded in a doc; P = partly recorded, the extra file adds the rest; N = not recorded, the extra file is the record; S = skipped.
* **Deletable columns** are the Tier A (profiler output, staged binaries, regenerable genesis) and Tier B (bulky raw logs and sampler dumps) bytes from `DELETABLE.md`.
